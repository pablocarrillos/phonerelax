# Logos de los centros (prueba social)

Colocar aquí el logo de cada centro; la portada los detecta por nombre de
fichero y los muestra en tonos grises (color al pasar el ratón). Si el fichero
no existe, se muestra el nombre en texto.

Nombres esperados (svg, png, webp o jpg, por este orden de preferencia):

- `kensington-school.svg`
- `colegio-norfolk.svg`
- `colegio-san-fernando.svg`
- `escola-montcau-la-mola.svg`

Idealmente con fondo transparente y recortados sin márgenes; se pintan a 44px
de alto.
